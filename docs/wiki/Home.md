# 🚀 Bienvenido a la Wiki de NetOpsToolkit

**NetOpsToolkit** es una suite de herramientas de red 100% *client-side*, diseñada por y para ingenieros de redes. Su objetivo es reemplazar los scripts sueltos de Python y hojas de Excel por una única aplicación web rápida, visual y privada.

## 🎯 ¿Por qué NetOpsToolkit?
1. **Privacidad Absoluta**: Al ser 100% *client-side*, ninguna de tus configuraciones, direcciones IP o secretos viaja a un servidor de backend. 
2. **Lean Architecture**: Todo carga de inmediato. Sin dependencias pesadas de frameworks UI.
3. **Productividad CCIE**: Herramientas pensadas para reducir el error humano en entornos de producción (BGP, OSPF, ACLs).
